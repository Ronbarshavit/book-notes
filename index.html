Add your audiobook

On iPhone, install first
  1. Tap Share → Add to Home Screen.
  2. Open Book Notes from the new icon. The Home Screen app keeps its own storage, so files added here in Safari won't appear there.
  3. Then tap Choose MP3 files in the app.

Choose the MP3 chapters you saved from Telegram (in the Files app). They're stored only on this device and never uploaded.

In Files, tap Select (top right), then Select All, or tap each chapter, then Open. You can add more later.
